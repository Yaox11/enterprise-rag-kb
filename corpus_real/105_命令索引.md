# 命令索引

> 按名称查找任意 difyctl 命令，并附带其完整参考的链接

| Command | 功能 |
| :- | :- |
| [`auth devices list`](https://docs.dify.ai/zh/cloud/cli/reference/auth-and-contexts#列出活跃会话) | 列出账户的活跃会话。 |
| [`auth devices revoke`](https://docs.dify.ai/zh/cloud/cli/reference/auth-and-contexts#撤销会话) | 撤销某个会话，或除当前会话外的所有会话。 |
| [`auth list`](https://docs.dify.ai/zh/cloud/cli/reference/auth-and-contexts#列出已保存的上下文) | 列出已保存的登录上下文。 |
| [`auth login`](https://docs.dify.ai/zh/cloud/cli/reference/auth-and-contexts#登录) | 通过 OAuth 设备流程登录 Dify 主机。 |
| [`auth logout`](https://docs.dify.ai/zh/cloud/cli/reference/auth-and-contexts#退出登录) | 退出当前主机的登录。 |
| [`auth whoami`](https://docs.dify.ai/zh/cloud/cli/reference/auth-and-contexts#查看当前身份) | 打印当前登录的身份。 |
| [`describe app`](https://docs.dify.ai/zh/cloud/cli/reference/apps#查看应用) | 查看单个应用的元数据和输入。 |
| [`env list`](https://docs.dify.ai/zh/cloud/cli/reference/environment-variables#查看已设置的变量) | 列出 difyctl 可识别的环境变量。 |
| [`export studio-app`](https://docs.dify.ai/zh/cloud/cli/reference/apps#导出应用) | 将工作室应用的 DSL 配置导出为 YAML。 |
| [`get app`](https://docs.dify.ai/zh/cloud/cli/reference/apps#列出应用) | 列出应用，或查询单个应用。 |
| [`get workspace`](https://docs.dify.ai/zh/cloud/cli/reference/workspaces#列出工作空间) | 列出你所属的工作空间。 |
| [`help`](https://docs.dify.ai/zh/cloud/cli/reference/help) | 在终端中获取帮助，包括机器可读的 JSON。 |
| [`import studio-app`](https://docs.dify.ai/zh/cloud/cli/reference/apps#导入应用) | 从 DSL 文件或 URL 导入工作室应用。 |
| [`resume app`](https://docs.dify.ai/zh/cloud/cli/reference/apps#恢复已暂停的工作流) | 恢复已暂停的工作流运行。 |
| [`run app`](https://docs.dify.ai/zh/cloud/cli/reference/apps#运行应用) | 运行应用并打印响应。 |
| [`skills install`](https://docs.dify.ai/zh/cloud/cli/reference/skills#安装技能) | 将 difyctl 技能安装到检测到的编码 Agent 中。 |
| [`use account`](https://docs.dify.ai/zh/cloud/cli/reference/auth-and-contexts#切换当前账户) | 切换当前主机上的活跃账户。 |
| [`use host`](https://docs.dify.ai/zh/cloud/cli/reference/auth-and-contexts#切换当前主机) | 切换当前的 Dify 主机。 |
| [`use workspace`](https://docs.dify.ai/zh/cloud/cli/reference/workspaces#切换工作空间-cloud) Cloud | 切换当前活跃的工作空间。 |
| [`version`](https://docs.dify.ai/zh/cloud/cli/reference/version) | 显示客户端和服务端版本及兼容性。 |

[全局标志](https://docs.dify.ai/zh/cloud/cli/reference/global-flags.md) 适用于所有命令。

关于输出格式、错误和退出码，详见 [输出格式与退出码](https://docs.dify.ai/zh/cloud/cli/reference/output-formats-and-exit-codes.md)。

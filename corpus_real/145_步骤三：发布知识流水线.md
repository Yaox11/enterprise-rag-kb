# 步骤三：发布知识流水线

完成知识流水线的编排和调试后，点击 **发布** 并在弹窗中点击 **确认**，即成功发布知识流水线。

![发布确认](https://mintcdn.com/dify-6c0370d8/Z6MqdkI3dck9_1H6/images/use-dify/knowledge/create-knowledge-pipeline-12-01.png?fit=max\&auto=format\&n=Z6MqdkI3dck9_1H6\&q=85\&s=b8c440e827a9faf3d85238e78b0fa07e)

![发布成功](https://mintcdn.com/dify-6c0370d8/Z6MqdkI3dck9_1H6/images/use-dify/knowledge/create-knowledge-pipeline-12.png?fit=max\&auto=format\&n=Z6MqdkI3dck9_1H6\&q=85\&s=a65370fe17c5cf5d71f10fb776c04a5a)

> [!WARNING]
>
> **注意：知识流水线发布后，分段结构无法进行修改。**
> 由于分段结构会影响知识库的存储方式和检索召回策略，为确保数据一致性和用户体验，当前每个知识库仅支持 **一种分段结构**。

![发布完成](https://mintcdn.com/dify-6c0370d8/Z6MqdkI3dck9_1H6/images/use-dify/knowledge/create-knowledge-pipeline-13.png?fit=max\&auto=format\&n=Z6MqdkI3dck9_1H6\&q=85\&s=411ba3f6e3b8088271c8cb1166bed7d1)

成功发布后，你可以进行如下操作：\
\


**添加文档（Go to add documents)**\
点击此选项可以跳转到知识库选择数据源界面，你可以直接上传文档。\
\


**访问 API（Access API Reference)**
前往 API 文档页面，你可以获取知识库的 API 调用方法和说明。\
\


**发布为流水线（Publish as a Knowledge Pipeline)**\
你可以点击发布为知识流水线将该流水线保存为可复用的模版，该模版将出现在自定义模版中。

> [!NOTE]
>
> **发布为知识流水线** 仅 Professional 和 Team 套餐可用。Sandbox 账户无法将流水线发布为可复用模板。[升级套餐](https://dify.ai/zh/pricing) 以解锁此功能。

# 使用 Dify

工作空间是一切工作的起点：构建 AI 应用，接入你自己的数据，再将其发布并持续监控。

[快速开始](https://docs.dify.ai/zh/quick-start.md)

[核心概念](https://docs.dify.ai/zh/learn/key-concepts.md)

> **[编排](https://docs.dify.ai/zh/cloud/use-dify/build/workflow-chatflow.md)**
>
> 在可视化画布上构建 Workflow 与 Chatflow，以及 Agent、聊天助手等。

> **[知识库](https://docs.dify.ai/zh/cloud/use-dify/knowledge/readme.md)**
>
> 导入文档与数据，应用即可检索和引用这些内容。

> **[发布](https://docs.dify.ai/zh/cloud/use-dify/publish/README.md)**
>
> 将应用发布为 Web 应用、嵌入网站，或通过 API 调用。

> **[监控](https://docs.dify.ai/zh/cloud/use-dify/monitor/analysis.md)**
>
> 跟踪用量、查看日志，并通过标注优化回答。

> **[集成](https://docs.dify.ai/zh/cloud/use-dify/workspace/plugins.md)**
>
> 接入模型供应商、工具、数据来源和外部服务。
